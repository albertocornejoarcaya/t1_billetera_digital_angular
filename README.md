# Billetera Digital

Aplicación web desarrollada con Angular para gestionar una billetera digital, permitiendo visualizar el saldo y registrar movimientos financieros.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML5
- Node.js
- npm

## Funcionalidades
- Visualización del saldo disponible.
- Registro de nuevos movimientos.
- Visualización de movimientos realizados.
- Interfaz web sencilla y responsive.
